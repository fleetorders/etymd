# clothaid

An **agent-agnostic agentic-workflow CLI**. Run it inside a project to reckon it and install,
migrate, or optimise a disciplined agent workflow — one source-of-truth operating contract plus
thin per-agent adapters (Claude Code, Cursor, Copilot) — then keep earning its place with
freshness audits, loop metrics, a keyless dashboard, and knowledge that grows from the projects it
learns from.

Distilled from the pepshop frontrunner workflow and lessons across nx-monorepo, spa-bff, and
cra-legacy.
